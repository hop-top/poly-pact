# Go dependencies

This file registers third-party Go dependencies for the PACT protocol's Go implementation (`go/core`, `go/adapter`, `cli`). A dependency reaches `go.mod` only after a vet with `rsx` in deep mode (`rsx analyze <repo> --mode deep`) passes the balanced policy check. A failure is recorded here instead of a pin. Each row captures what `rsx` reported plus separately verified facts – anything not verified is marked "to verify". The `require` line itself is added in the work that implements the code using the dependency, not here. Rows are appended as dependencies are vetted; existing rows are only edited to correct them or record a re-vet.

- **Dependency** – the Go module path
- **Used by** – the adapter or tool that imports it
- **Version to pin** – the exact version to put in `go.mod`
- **License** – the SPDX license identifier
- **Maintenance** – `rsx` maintenance signals and separately verified facts, including the date of the latest release
- **rsx verdict** – the `rsx` result under the balanced policy, with the date of the vet
- **Constraint** – where the dependency may or may not be imported; `none` when there is no constraint
