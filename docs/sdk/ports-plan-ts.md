## 2. Source rules

Type stripping runs the sources directly under `node --test`, so the sources use erasable syntax only. The compiler enforces it through `tsconfig`: `erasableSyntaxOnly` (rejects `enum` and parameter properties, TS1294), `verbatimModuleSyntax`, `allowImportingTsExtensions` and `rewriteRelativeImportExtensions` (all probed 2026-10-16 on 7.0.2). Biome echoes it in the editor with `style/noEnum`, `style/noParameterProperties` and `style/useImportType` (all fire on 2.5.15, probed 2026-10-16). Relative imports carry `.ts`.

## 4. Idioms

- **Errors.** One `Error` subclass per Go error family with a `kind`, `reason` or `code` discriminant holding the Go strings. `cause` carries the wrapped error. `reasonOf`, `codeOf` and `hasKind` walk `cause`.
- **Bytes.** `Uint8Array` on every public signature; `Buffer` only inside `node:` calls. Base64url encode with `Buffer.toString('base64url')`. Decode canonically: scan the alphabet, then require `Buffer.from(s, 'base64url').toString('base64url') === s` (rejects padding, spare bits and length 1 mod 4). `Buffer.from` alone accepts `AQ==`, `AR`, embedded spaces and newlines (probed 2026-10-16).
- **Comparison.** `timingSafeEqual` for digests and thumbprints, after an explicit length check: it throws `ERR_CRYPTO_TIMING_SAFE_EQUAL_LENGTH` on unequal lengths.
- **JSON.** Wire input goes through `strictjson.parse` or `decode`, never `JSON.parse`. Output goes through the JCS writer or a serializer that keeps raw values.
- **Schema module.** `ajv` is CommonJS. Under NodeNext the import is `import Ajv2020Mod from 'ajv/dist/2020.js'; const Ajv2020 = Ajv2020Mod.default` (the plain default import fails `tsc` 7.0.2 with TS2351; probed 2026-10-16). Strict mode throws on an unregistered format, so `addFormat('uri', matcher)` runs before `compile`.
- **Integers.** Parsed from the token text, rejected outside `±(2^53-1)` before conversion; `BigInt` only inside S normalization.
- **Async.** Adapter functions return promises; core primitives are synchronous.
- **ESM only.** Node 22.12 and later load ESM from `require` unflagged, so with the 22.18 floor CommonJS consumers can `require('@hop-top/pact')`; no dual build.
- **Entry points.** `src/vectors/main.ts`, the manifest check and the `tool evaluate {dir}` skeleton take plain argv with no command-line framework, and `@hop-top/pact` never depends on the kit console framework; a later user-facing command-line tool is a separate package built on it ([ports-plan.md](ports-plan.md), section 4).

## 5. Dependencies and guard

Runtime: `ajv` 8.20.0. Development: `typescript` 7.0.2, `@biomejs/biome` 2.5.15, `@types/node` (to vet), `ajv-formats` 3.0.1 (oracle for the in-house `uri` matcher only). Everything else uses `node:` builtins: `node:crypto`, `node:fs`, `node:path`, `node:http`, `node:test`. The adapter stack, manifest, binding and case loader add no dependency.

`test/depcheck.test.ts` checks all four dependency maps of `package.json` (`dependencies` = the vetted runtime set; `devDependencies` = the vetted development set; `peerDependencies` and `optionalDependencies` empty), and that every import under `src/` is relative, `node:*` or a vetted runtime package; it has a negative control on a copy. `make ts-build` runs `npm pack --dry-run --json` and asserts the file list is `dist/**`, `schema/pact.schema.json`, `README.md`, `LICENSE`, `package.json`.

## 6. Conformance strategy

1. **Vectors harness** per the shared plan (section 5): result grammar, entry handling, key rule, exit status. `make ts-test` and CI set `PACT_REQUIRE_VECTORS=1`.
2. **Unit tests** ported one-to-one from the Go test files, including the full 10 000 rows of `vectors/jcs/numbers.json` and Go's `roundtrip_test` (strict decode, serialize, strict decode, JCS of both equal) for every `$defs` entry over the Appendix B examples.
3. **Draft-reading tests**: the section 7.3 typ table, the section 20.1 limits and lifetimes, the freshness profile vocabulary, read from `spec/` at test time.
4. **Schema drift**: generated tables against the vendored schema; vendored schema against `spec/v1.0/schemas` by `make ts-check-schema`.
5. **Property test** for JCS over random trees (idempotence, round trip through strict parse); Go's nightly fuzz stays the deep one.
6. **Adapter suite**: the 88 common cases against the memory adapter and the broken catalogue (each defect fails its cases; all defects fail all; no defect passes all; every case targeted), plus the case-file rule, registered-in-manifest and draft-heading tests.
7. **Mutation patches** (shared plan, section 5.6), listed per task in section 9.

- `ci-ts.yml`: remove the guards when the scaffold lands. Steps: `mise run install`, `make ts-lint` (Biome and `tsc --noEmit`; `node --test` does not type-check), `make ts-test`, `make ts-vectors`, `make ts-check-schema`, `make ts-build`. Add `spec/v1.0/draft.md` and `spec/v1.0/profiles/freshness.md` to the path filters.

- Node matrix `{22, 24, 26}`, ubuntu; a Windows leg for `make ts-test` from the manifest task on (paths and symbolic links).
- `make ts-mutants` nightly and on pull requests that add a patch.

## 10. Risks

| Risk | Mitigation |
|---|---|
| `node:http` cannot give the raw request-target or header order in some case | phase-0 probe; the conformance path uses `RawRequest` only |
| Millisecond time versus Go nanoseconds | exact second-and-remainder comparisons; ledger deviation; no fixture is sub-second |
| Biome lags `typescript` 7 syntax | the compiler flags are the primary guard |
| Leak scan relies on error messages carrying no credentials | the leak-scan tests over values and errors are ported |
| Node floor drift | the matrix runs the floor on every change |
